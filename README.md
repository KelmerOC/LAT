# PLATAFORMA LÁCTEA COMUNITARIA · LAT (VERSIÓN COMPACTA UNIVERSITARIA)

Versión didáctica y condensada del sistema de acopio y transformación láctea LAT, optimizada para sustentaciones académicas, evaluación de arquitectura de software y despliegue directo en el entorno local Apache / XAMPP.

---

## 1. Características Principales Preservadas
1. **Framework Laravel 11/12:** Arquitectura limpia MVC + Capa de Servicios (`LacteoService`).
2. **Diseño Visual No Genérico:** Brex Style Flat Fill Contrast (cero sombras, cero bordes artificiales, paleta acuarela azul celeste, cifras delgadas `font-weight: 300` e isotipo de frasco de leche + queso).
3. **Módulo 1 - Acopio por Voz y Modo 1 Mano:** Dictado Web Speech API con síntesis de confirmación de audio y botonera táctil rápida.
4. **Módulo 2 - Triage Sanitario Ético (74°):** Separación inmediata entre leche óptima para tina y leche ácida para quesillos frescos de 4 días (política de cero desperdicio).
5. **Módulo 3 - Monitor Térmico de Tina y Receta:** Curva de enfriamiento (72 °C -> 36-40 °C) y dosificación matemática exacta (cuajo 2.5 ml / 100 L, sal 1.8 kg / 100 L, cultivo 1.0 g / 100 L).
6. **Módulo 4 - Liquidación Quincenal al 0% y Cuentas Claras:** Deducción de adelantos, pago de ayuda del día sin DNI (Ley N.° 29733) y exportación de balance mensual en formato CSV oficial para bancos y SUNAT.
7. **Optimizaciones de Software:**
   - Prevención del problema N+1 en liquidaciones mediante agregaciones SQL agrupadas.
   - Índices compuestos en base de datos para evitar escaneo completo de tablas (`idx_acopios_fecha_calidad`, etc.).
   - Tipografía tabular delgada de alta legibilidad en monitores industriales.
